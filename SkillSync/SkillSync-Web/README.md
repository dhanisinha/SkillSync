# SkillSync Web Application

A state-of-the-art developer platform frontend built with React, Vite, and Lucide Icons. Designed to mirror and integrate with the SkillSync Java Backend engine.

## Features
- **Corporate Tech Clubs**: Google, Amazon, Meta, and Microsoft developer hubs with discussion boards and interview experience logs.
- **Collaborative Projects**: Skill-based project discovery, team member rosters, and task Kanban boards.
- **Mentor Discovery & Search**: Smart filter for verified industry mentors and programming skills.
- **Profile & Skill Management**: Interactive skill chip manager with proficiency levels and mentor verification toggle.
- **State Persistence**: Instant `localStorage` persistence with mock REST endpoints ready for backend integration.

## Getting Started

```bash
# Install dependencies
npm install

# Start Vite local development server
npm run dev
```
